Installer sur ton téléphone

  • Télécharge le fichier

    Touche le bouton ci-dessus depuis ton téléphone Android — le fichier .apk se télécharge directement.

  • Autorise l'installation

    Android peut demander d'autoriser "l'installation d'applications inconnues" pour ton navigateur. C'est normal pour une app installée hors Play Store — accepte pour continuer.

  • Ouvre et installe

    Ouvre le fichier téléchargé depuis tes notifications ou ton dossier Téléchargements, puis suis les instructions à l'écran.
